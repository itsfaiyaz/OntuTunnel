### What's new in 2.1.0

**Remote access: reach your computer from anywhere** (My server mode, Mac and Windows/Linux)
- Your computer gets a fixed address on your server's IP, for example `34.47.187.74:2201` for SSH. It stays the same when your Wi-Fi or IP changes, from anywhere in the world.
- Quick buttons:
  - **SSH (22)** on Mac, Windows and Linux;
  - **Remote Desktop (3389)** on Windows;
  - **Screen Sharing (5900)** on Mac.
- **Copy SSH config**: paste it on the other computer, then just `ssh <computer-name>`.
- **Computers allowed without a password**: paste another computer's public key and it logs in without a password. On Windows, OntuTunnel writes the administrators' key file with the permissions OpenSSH needs.
- **Windows extras:** a button turns on Windows' own OpenSSH Server, and another opens the Remote Desktop settings.
- **First-time checklist:** the SSH server on this computer, a one-time firewall rule for the server (`2201-2299, 5901-5999`, which covers other computers too), and a test from the internet.
- **Several computers on one server:** each one gets its own port, picked automatically (2201, 2202 …), and a port another computer uses is refused.
- **On the server:** OntuTunnel only adds its own `ontutunnel-tcp-<port>` systemd units. nginx, sshd and your sites are not touched.

**"My server" is now in tabs:** **1 · Connect** stays at the top, then **Server setup**, **SSH key** and **Remote access**.

**SSH config file** (`~/.ssh/config`)
- See your servers' short names (like `adimyra-vm`).
- Save or update the current server with valid syntax: a backup is kept, the file is checked with `ssh`, and a wrong file is put back.
- Open the file to edit it (Terminal or TextEdit on Mac, Notepad on Windows).

**Fixes**
- Windows/Linux: a server written as an SSH config short name now resolves to its real IP.

### Which file do I need?
| System | File |
|---|---|
| macOS 14+ (Apple Silicon & Intel) | `OntuTunnel-2.1.0.dmg` (signed & notarized) |
| Windows 10/11 x64 | `OntuTunnel-Setup-2.1.0-x64.exe` (or the portable zip) |
| Windows on ARM | `OntuTunnel-2.1.0-windows-arm64-portable.zip` |
| Debian / Ubuntu | `ontutunnel_2.1.0_amd64.deb` / `_arm64.deb` |
| Fedora / RHEL | `ontutunnel-2.1.0-1.x86_64.rpm` / `.aarch64.rpm` |
| Other Linux | `OntuTunnel-2.1.0-linux-<arch>.tar.gz` |

**Updating:** install 2.1.0 over the old version; your settings are kept. Windows builds aren't signed yet, so SmartScreen may ask you to choose **More info → Run anyway**.

`SHA256SUMS.txt` lists a checksum for every file.

### What's new in 2.0.2

**The Mac app is now signed and notarized by Apple**
- `OntuTunnel-2.0.2.dmg` is signed with the Developer ID of **Adimyra Systems Private Limited** and notarized by Apple.
- It opens like any other app: no more "Apple could not verify…" message and no Privacy & Security steps.
- The build scripts can now sign and notarize: set `SIGN_ID` and `NOTARY_PROFILE` for `scripts/make-dmg.sh`.

No other changes from 2.0.1.

### Which file do I need?
| System | File |
|---|---|
| macOS 14+ (Apple Silicon & Intel) | `OntuTunnel-2.0.2.dmg` (signed & notarized) |
| Windows 10/11 x64 | `OntuTunnel-Setup-2.0.2-x64.exe` (or the portable zip) |
| Windows on ARM | `OntuTunnel-2.0.2-windows-arm64-portable.zip` |
| Debian / Ubuntu | `ontutunnel_2.0.2_amd64.deb` / `_arm64.deb` |
| Fedora / RHEL | `ontutunnel-2.0.2-1.x86_64.rpm` / `.aarch64.rpm` |
| Other Linux | `OntuTunnel-2.0.2-linux-<arch>.tar.gz` |

**Updating:** install 2.0.2 over the old version; your settings are kept.
- **Mac:** because the app's signature changed, macOS may ask once whether OntuTunnel can use its saved keychain items. Choose **Always Allow**.
- **Windows:** the builds aren't signed yet, so SmartScreen may ask you to choose **More info → Run anyway**.

`SHA256SUMS.txt` lists a checksum for every file.

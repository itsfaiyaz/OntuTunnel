### What's new in 1.1.2

**Windows is now a real desktop app**
- OntuTunnel opens in its own window. No browser is needed: it uses Microsoft Edge WebView2, which is built into Windows 10/11.
- An icon next to the clock (tray) shows the status. Right-click it to open OntuTunnel, open the dashboard in a browser, or quit.
- Closing the window keeps your sites online. Starting OntuTunnel again just brings the window back.
- With "Start OntuTunnel when I sign in to Windows", it starts quietly in the tray.
- The `.exe` shows the OntuTunnel icon, version and Ontu Technologies in its properties.

**My static IP: sites open from the same computer**
- OntuTunnel adds each enabled site to this computer's hosts file (`127.0.0.1`), so they open even when the router can't reach its own public IP. Windows asks for admin permission only when the list of sites changes.
- Your own lines in the hosts file are never changed. If a hand-added line for the same site would win, the Logs tell you.
- You can turn this off in Settings.

**Fixes**
- Windows/Linux: the DNS check now asks Google/Cloudflare directly, so a hosts-file line no longer shows up as your site's DNS.
- Static IP health: if your public IP can't be tested from inside your home network, OntuTunnel tests this computer directly and says what's missing, for example router port forwarding.

### Which file do I need?
| System | File |
|---|---|
| macOS 14+ (Apple Silicon & Intel) | `OntuTunnel-1.1.2.dmg` |
| Windows 10/11 x64 | `OntuTunnel-Setup-1.1.2-x64.exe` (or the portable zip) |
| Windows on ARM | `OntuTunnel-1.1.2-windows-arm64-portable.zip` |
| Debian / Ubuntu | `ontutunnel_1.1.2_amd64.deb` / `_arm64.deb` |
| Fedora / RHEL | `ontutunnel-1.1.2-1.x86_64.rpm` / `.aarch64.rpm` |
| Other Linux | `OntuTunnel-1.1.2-linux-<arch>.tar.gz` |

**Updating on Windows:** run the new installer. It replaces the old version and keeps your settings.

The builds aren't signed yet. On first open, macOS asks you to allow the app in **Privacy & Security**, and Windows SmartScreen asks you to choose **More info → Run anyway**.
`SHA256SUMS.txt` lists a checksum for every file.

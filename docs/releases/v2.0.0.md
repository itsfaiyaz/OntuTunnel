## OntuTunnel 2.0

The biggest update since the first release. OntuTunnel is now a real desktop app on Windows, works well when several computers share one server, and was security-checked and tested on real machines.

### Highlights

**Windows desktop app**
- OntuTunnel opens in its own window (Microsoft Edge WebView2, built into Windows 10/11), not the browser.
- An icon next to the clock shows the status. Closing the window keeps your sites online.
- The installer allows OntuTunnel in Windows Firewall and closes a running copy before updating.

**One server, several computers**
- Several computers can publish sites through the same server, with nginx or Caddy. Each computer only adds and removes its own sites.
- Tunnel ports used by another computer are never reused, even while that computer is offline.
- Publishing a domain that another computer already serves is refused, with a clear message.
- **Remove from server** removes only this computer's sites. The shared parts stay while other computers still use them.
- Caddy mode keeps one file per site.

**Easier SSH keys** (Mac, Windows, Linux)
- See the keys on your computer, with **Copy** and **Use this** buttons.
- No key yet? Type a user name and click **Create key**. Google Cloud creates that user by itself when you add the key.
- Step-by-step instructions for Google Cloud and other servers.

**Hosts file page** (Mac, Windows, Linux)
- See, add, change and delete entries in this computer's hosts file from the app. Saving asks for admin permission once.
- In *My static IP* mode, OntuTunnel adds your sites to the hosts file by itself, so they open on this computer even when the router can't reach its own public IP.

**First-time HTTPS checklist** for *My static IP*
- The checklist covers: ports 80/443, Windows Firewall, DNS, router port forwarding, a **test from the internet** (run from your own server), and the certificate for each site.

**Update notice**
- OntuTunnel checks GitHub twice a day. When a new version is out, it shows **New version available → Download**: in the dashboard, and on Mac also in the menu bar.

**Security**
- The dashboard at `localhost:7777` can no longer be used by other websites open in your browser.
- Domains and Frappe site names are checked strictly before anything is sent to the server.
- The DNS check asks Google/Cloudflare directly, so the hosts file can't fool it.

**Fixes**
- Leaving *My static IP* removes OntuTunnel's hosts-file entries.
- A clear message when Windows keeps port 80/443 for another service, such as IIS.
- Fast reconnect after a network change, and the keep-awake option, from 1.1.x are included.

Every release is now tested before it is published:
- on a real Windows machine: app window, single copy, security, hosts file, static IP, SSH key, firewall;
- on real nginx and Caddy servers shared by three computers.

### Which file do I need?
| System | File |
|---|---|
| macOS 14+ (Apple Silicon & Intel) | `OntuTunnel-2.0.0.dmg` |
| Windows 10/11 x64 | `OntuTunnel-Setup-2.0.0-x64.exe` (or the portable zip) |
| Windows on ARM | `OntuTunnel-2.0.0-windows-arm64-portable.zip` |
| Debian / Ubuntu | `ontutunnel_2.0.0_amd64.deb` / `_arm64.deb` |
| Fedora / RHEL | `ontutunnel-2.0.0-1.x86_64.rpm` / `.aarch64.rpm` |
| Other Linux | `OntuTunnel-2.0.0-linux-<arch>.tar.gz` |

**Updating from 1.x:** install 2.0 over the old version; your settings are kept.
- **Caddy mode servers** move to the new one-file-per-site layout on the first sync.
- **Several computers on one Caddy server:** update all of them, so each one re-publishes its sites in the new layout.

The builds aren't signed yet. On first open, macOS asks you to allow the app in **Privacy & Security**, and Windows SmartScreen asks you to choose **More info → Run anyway**.
`SHA256SUMS.txt` lists a checksum for every file.

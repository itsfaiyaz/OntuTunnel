### What's new in 2.1.1

**Fixes**
- **WebSockets now work through your domains in My server (nginx) mode.** The nginx file OntuTunnel writes for each domain now passes WebSocket upgrades through, so things like Next.js dev live reload, Vite HMR and chat sockets work on the public address. Open OntuTunnel 2.1.1 once and it rewrites the file for each of your domains.
- **Web dashboard:** adding a domain that is already in the list now updates that service instead of making a second copy.

### Which file do I need?
| System | File |
|---|---|
| macOS 14+ (Apple Silicon & Intel) | `OntuTunnel-2.1.1.dmg` (signed & notarized) |
| Windows 10/11 x64 | `OntuTunnel-Setup-2.1.1-x64.exe` (or the portable zip) |
| Windows on ARM | `OntuTunnel-2.1.1-windows-arm64-portable.zip` |
| Debian / Ubuntu | `ontutunnel_2.1.1_amd64.deb` / `_arm64.deb` |
| Fedora / RHEL | `ontutunnel-2.1.1-1.x86_64.rpm` / `.aarch64.rpm` |
| Other Linux | `OntuTunnel-2.1.1-linux-<arch>.tar.gz` |

**Updating:** install 2.1.1 over the old version; your settings are kept. Windows builds aren't signed yet, so SmartScreen may ask you to choose **More info → Run anyway**.

`SHA256SUMS.txt` lists a checksum for every file.

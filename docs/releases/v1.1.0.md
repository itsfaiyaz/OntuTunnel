The first public release of OntuTunnel. It puts the app running on your computer on your own domain, with HTTPS.

### Highlights
- **macOS, Windows and Linux** apps
- **Three ways to go live:** your own server (SSH), your static IP, or a free Cloudflare Tunnel
- **Automatic HTTPS** certificates, created and renewed for you
- **Wildcard domains:** one DNS record, unlimited sites
- **Running ports list:** click Publish to put an app online, and hide ports you never publish
- **Health checks** for app, DNS and HTTPS, from the internet's side
- **Fast reconnect:** a new Wi-Fi, a hotspot or a new IP reconnects in seconds, and old server sessions are cleaned up
- **Keep this computer awake** option in Settings
- **Browser dashboard** at `http://localhost:7777`, with phone access through an access key
- **Safe on existing servers:** it adds only its own nginx files, checks with `nginx -t` first, and rolls back if anything fails

### Which file do I need?
| System | File |
|---|---|
| macOS 14+ (Apple Silicon & Intel) | `OntuTunnel-1.1.0.dmg` |
| Windows 10/11 x64 | `OntuTunnel-Setup-1.1.0-x64.exe` (or the portable zip) |
| Windows on ARM | `OntuTunnel-1.1.0-windows-arm64-portable.zip` |
| Debian / Ubuntu | `ontutunnel_1.1.0_amd64.deb` / `_arm64.deb` |
| Fedora / RHEL | `ontutunnel-1.1.0-1.x86_64.rpm` / `.aarch64.rpm` |
| Other Linux | `OntuTunnel-1.1.0-linux-<arch>.tar.gz` |

The builds aren't signed yet. On first open, macOS asks you to allow the app in **Privacy & Security**, and Windows SmartScreen asks you to choose **More info → Run anyway**.
`SHA256SUMS.txt` lists a checksum for every file.

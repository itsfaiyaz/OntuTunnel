### What's new in 2.0.1

**Fix: several computers on one server, after a server reboot**
- OntuTunnel's server scripts used fixed file names in the server's `/tmp`: `ontutunnel-nginx-test`, `ontutunnel-certbot` and `ontutunnel-caddy.log`.
- When two computers log in with different SSH users, those files belonged to whichever user ran first after a reboot. The other computer's setup then stopped with "Permission denied".
- Now every run uses its own temporary folder and removes it at the end, so any number of computers and SSH users work together, before and after a reboot.

**Update every computer that uses the same server to 2.0.1.**

### Which file do I need?
| System | File |
|---|---|
| macOS 14+ (Apple Silicon & Intel) | `OntuTunnel-2.0.1.dmg` |
| Windows 10/11 x64 | `OntuTunnel-Setup-2.0.1-x64.exe` (or the portable zip) |
| Windows on ARM | `OntuTunnel-2.0.1-windows-arm64-portable.zip` |
| Debian / Ubuntu | `ontutunnel_2.0.1_amd64.deb` / `_arm64.deb` |
| Fedora / RHEL | `ontutunnel-2.0.1-1.x86_64.rpm` / `.aarch64.rpm` |
| Other Linux | `OntuTunnel-2.0.1-linux-<arch>.tar.gz` |

**Updating:** install 2.0.1 over the old version; your settings are kept.

The builds aren't signed yet. On first open, macOS asks you to allow the app in **Privacy & Security**, and Windows SmartScreen asks you to choose **More info → Run anyway**.
`SHA256SUMS.txt` lists a checksum for every file.
